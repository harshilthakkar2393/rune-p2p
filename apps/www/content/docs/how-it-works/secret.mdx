---
title: The secret
description: Sixteen random bytes, shown as twelve words. The key to the room, not to your notes.
---

Everything about pairing rests on one value: **sixteen random bytes** generated on the first device. Rune shows them as twelve English words, using the same word list as cryptocurrency wallets, because words are easier to type across a room than 32 hex characters.

## What it is for

The secret is a **rendezvous key**. From it, every device derives the same room name and the same handshake password. Devices holding it find each other; devices without it can't even name the room. That is the entire membership model. There is no account behind it.

## What it is not

It is **not** an encryption key for your notes. Notes on a device are stored as they are; see [Encryption and the threat model](/docs/how-it-works/encryption). The secret only controls who can join the sync room.

## Losing it

Costs almost nothing. Your notes are already on every paired device in full. If you lose the words:

1. On any device, create a new pairing code. That device is now in a new room.
2. Pair the others with the new code.

Nothing needs recovering because nothing was locked.

## Sharing it

Is the same as sharing the space. A second person with the words would join as another "device" and see everything. Rune has no interface for that on purpose. If it happened by accident, create a new code on your devices and re-pair them; the other party is left with whatever they had already received.

## Where it is stored

On each device, locally, never synced, never sent. The link form (`/pair#s=…`) keeps it after the `#`, which browsers never transmit to a server.
