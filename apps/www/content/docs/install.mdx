title: Install

Rune is a web app. You can use it in a browser tab, but you should install it. Installed, it opens offline, keeps its storage, and the phone treats it like an app: no address bar, no browser toolbar, the keyboard and the dock behave.

## iPhone and iPad

1. Open Rune in **Safari**. Other browsers on iOS can't install web apps.
2. Tap **Share**, then **Add to Home Screen**.
3. Open it from the home screen from now on.

The tab and the installed app are two separate copies with separate storage. Pair the installed app as its own device; see [Pair a second device](/docs/pair).

## Mac and desktop browsers

Rune works in Safari, Chrome, Edge and Firefox. Chrome and Edge offer **Install** in the address bar; Safari on macOS 14 and later has **File, Add to Dock**. Installing on desktop is optional. In a tab everything works, including sync.

## Why installing matters

**Storage.** Browsers may clear a site's data when space is low, or after a stretch of not visiting. An installed app gets its own storage budget, and Rune asks the system to mark that storage as persistent. The Devices page shows whether that was granted.

**Offline.** The installed app starts without a network. The tab may not.

**Updates.** When a new version is available a small "Update ready" pill appears. Tap it, the app reloads. Nothing is downloaded silently in the background.

## What "keep notes safe" means here

Installing protects against the browser tidying up. It does not protect against losing the device. For that, pair a second device, and export what matters; see [Export and backup](/docs/using/export).
