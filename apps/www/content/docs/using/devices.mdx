## Before pairing

The page offers **Create pairing code** and **Have a code?**. See [Pair a second device](/docs/pair).

## After pairing

**Online** beside a device means there is a direct connection to it right now. If a device you know is open isn't listed, give it a few seconds; both sides rejoin the room when they return to the foreground.

**Reconnecting** appears briefly after the app comes back from the background or the network changes. If nothing is online after that, the other devices simply aren't open.

## This device

- **Name.** How this device is labelled on other devices and in page details ("created on iPhone"). Rename it here. Names are per device and don't sync.
- **Installed.** Whether Rune is running as an installed app or in a browser tab. If not installed, the page says how.
- **Storage.** Whether the browser granted persistent storage. If not, install the app and grant it when asked.
- **Offline.** Whether the app can start without a network.

## Unpair

Forgets the pairing secret on this device. Its notes stay. Other devices are unaffected. Pair again at any time with a code from another device.
