## Export a page

Open the page, open the inspector (the panel on the right), press the download button. You get a Markdown file named after the page. Headings, lists, quotes, code and checklists survive; some block layouts are flattened, since Markdown has no way to express them.

## What counts as a backup

Rune's backup is **another paired device**. Every device holds every page in full. Two devices that sync now and then is a better backup than most cloud arrangements, because there is no single account to lose.

Export is for the other cases:

- Moving a page somewhere else.
- Keeping a copy of something that must outlive the app.
- The day all your devices are gone at once.

## What there isn't

No whole-space export yet, and no import. Both are straightforward on this model and are planned.
