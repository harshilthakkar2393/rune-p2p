---
title: Keyboard shortcuts
description: The few that exist.
---

| Keys | Does |
|---|---|
| ⌘ K | Search |
| ⌘ N | New page |
| ⌘ B | Show or hide the sidebar |
| / | Block menu, inside the editor |
| Esc | Close search or a menu |

On Windows and Linux, Ctrl stands in for ⌘.

Inside the editor, the usual text shortcuts apply: ⌘B bold, ⌘I italic, ⌘Z undo. Undo is per page and per device.
